# 老娄布道 · 男性情感博弈实战引擎

> "女有小红书，男有老娄叔" —— 百万男性粉丝的山东情感布道者

## 这是什么？

一个 Claude Code / Codex / Gemini CLI 的 **Skill**，将网络情感博主 **老娄布道** 的思想精髓内化为 AI 可执行的策略引擎。

老娄的核心信条：**所有亲密关系的本质是价值匹配 + 情绪博弈。男人的根基是自尊、自身社会价值和情绪主导权。失去主动权，就一定会被抛弃。**

这个 Skill 不做温柔安慰、不讲漂亮话、不煲鸡汤——它用最直白最扎心的糙话，把你从"舔狗思维"里打醒，帮你重建男性框架。

## 适用场景

| 你遇到的情况 | Skill 能帮你 |
|-------------|-------------|
| 被绿/被劈腿，纠结要不要原谅 | 告诉你为什么"背叛只有 0 次和无数次"，给出果断止损的完整方案 |
| 长期冷战/冷暴力，对方失联 | 教你用冷处理拿回主动权，不再卑微求和 |
| 追女生被忽冷忽热，多次邀约被拒 | 让你看清真实原因，撤回投入，投资自己 |
| 拼命花钱讨好，却被当提款机 | 重塑你的价值认知，停止无底线付出 |
| 在关系中越来越低位，没有话语权 | 教你立底线、控投入、重建男性框架 |

## 快速安装

一行命令搞定：

**Claude Code:**
```bash
mkdir -p ~/.claude/skills/lao-lou && curl -fsSL https://raw.githubusercontent.com/Wingstofree/lao-lou-skill-/master/SKILL.md -o ~/.claude/skills/lao-lou/SKILL.md
```

**Codex:**
```bash
mkdir -p ~/.agents/skills/lao-lou && curl -fsSL https://raw.githubusercontent.com/Wingstofree/lao-lou-skill-/master/SKILL.md -o ~/.agents/skills/lao-lou/SKILL.md
```

**Gemini CLI:**
```bash
mkdir -p ~/.gemini/skills/lao-lou && curl -fsSL https://raw.githubusercontent.com/Wingstofree/lao-lou-skill-/master/SKILL.md -o ~/.gemini/skills/lao-lou/SKILL.md
```

安装后重启 AI 即可。详细说明见 [INSTALL.md](INSTALL.md)。

## 与 chat-skills 的配合

| 场景 | 用哪个 |
|------|--------|
| 需要聊天话术、截图分析、回复文案 | [chat-skills](https://github.com/your-org/chat-skills) |
| 需要战略层面的男性框架重塑、底层认知重建 | **老娄（本 Skill）** |
| 追求阶段的推拉话术、邀约设计 | chat-skills |
| 被绿/被冷暴力/被当提款机后的止损与翻盘 | **老娄（本 Skill）** |

> 简单说：chat-skills 管"这句话怎么回"，老娄管"这件事怎么看、这仗怎么打"。
